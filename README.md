Abdelkader Mahdjoubi - Group 5
What it does
SmartBudget Manager is an Excel file that helps you follow your monthly budget. You enter your income and expenses and it calculates your balance, shows a chart of spending by category and warns you if you spend more than your limit.
What you need
•	Microsoft Excel 2016, 2019, 2021, Microsoft 365 or a compatible program
•	The file SmartBudget_Manager.xlsx
•	Basic Excel skills (open a file, type in a cell, save)
How to get started
1.	Open SmartBudget_Manager.xlsx. If you see a yellow bar, click Enable Editing.
2.	Go to the Dashboard and type your monthly budget limit.
3.	Go to the Transactions worksheet and fill the first empty row: date, description, category and the amount.
4.	Go back to the Dashboard to see the new balance and chart.
5.	Save the file with Ctrl + S.
Important
•	Put the amount in Income or in Expense, not in both.
•	Do not type in the grey cells. They contain formulas.
•	When expenses are higher than the budget limit, the warning turns red.
